# Nav Durga Group — Next.js
Responsive App Router implementation based on navdurgagroup.in.

## Run
```bash
npm install
npm run dev
```

## Content and assets
- Shared navigation/contact: `data/site.ts`
- Businesses, products, team, clients, gallery, Cloudinary links, videos and PDFs: `data/content.ts`
- Page-separated asset folders: `public/assets/<page>/{images,videos,pdfs}`
- Brand logo: `public/assets/global/images/navdurga-logo.png`

The visual system follows the supplied blue/red/silver logo. Pure black is not used in the authored theme.
